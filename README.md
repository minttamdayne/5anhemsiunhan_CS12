# Bài tập nhóm 5anhemsiunhan

Đây là sản phẩm bài tập Excel của nhóm **5anhemsiunhan**.

## Thành viên

1. Đinh Thị Minh Tâm
2. Bùi Thị Ngọc Trân
3. Nguyễn Khánh Linh
4. Ngô Lê Thuỷ Tiên
5. Phạm Thành Đạt

## Tệp bài làm

- [5anhemsiunhan_CS12.xlsx](./5anhemsiunhan_CS12.xlsx)

Workbook gồm các sheet hướng dẫn, tình huống, bài tập từ Bài 1 đến Bài 5, Xưởng, Thang điểm, Tổng hợp và dữ liệu hỗ trợ.
